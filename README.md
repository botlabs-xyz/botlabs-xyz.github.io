# 🚀 About Afterparty Bot Labs

Afterparty Bot Labs develops and maintains public Discord applications focused on improving online communities through automation, moderation, entertainment, and utility tools.

Our projects focus on:

- 🎵 Music
- 🛡️ Moderation
- ✅ Verification
- 🔧 Utilities
- 🎙️ Voice management
- 🤖 Automation
- 🌐 Community engagement

Our goal is to build reliable, secure, and user-friendly Discord applications for modern communities.
