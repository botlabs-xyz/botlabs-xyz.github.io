## About Afterparty Bot Labs

Afterparty Bot Labs develops and maintains public Discord bots focused on:

* Music
* Moderation
* Verification
* Utilities
* Temporary voice channels
* Community engagement
* Automation

Our goal is to build reliable and useful Discord applications for modern communities.
